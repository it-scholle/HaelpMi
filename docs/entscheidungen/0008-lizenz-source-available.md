# 0008 – Lizenz: source-available statt MIT

- Datum: 2026-08 (Entwurf), 2026-09-25 (HälpMi-Lizenz Fassung 1.0)
- Status: angenommen; rechtliche Prüfung vor einem echten Release offen
- Entschieden von: Repo-Owner

## Kontext
Vorgabe ist nur, dass der Quellcode öffentlich einsehbar ist; eine bestimmte Lizenz ist nicht
verlangt. Eine freizügige Lizenz wie MIT würde freie kommerzielle Weiterverwertung durch Dritte
erlauben.

## Entscheidung
`LICENSE` ist eine source-available-Lizenz (HälpMi-Lizenz): Quellcode öffentlich, kostenfrei für
Privatpersonen, kostenpflichtige Vereinbarung für Organisationen, keine Weiterverwertung zu
Konkurrenzprodukten. Komponenten Dritter in `THIRD-PARTY-NOTICES`.

## Folgen
- Vor einem echten Release: endgültige Lizenzwahl schriftlich bestätigen und den Text rechtskundig
  prüfen lassen.
- Das Pflichtenheft wird nicht rückwirkend geändert; maßgeblich ist `LICENSE`.
